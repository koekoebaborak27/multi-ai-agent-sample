## 20.1 マスタ分類一覧画面（MST-06）

マスタ分類の一覧を表示する。マスタ検索一覧画面（MST-01）の「マスタ分類の管理」ボタンから遷移する。

### 20.1.1 一覧

| 列        | 表示内容                           |
| -------- | ------------------------------ |
| マスタ分類コード | `MasterCategory.code` |
| マスタ分類名   | マスタ分類名                         |
| 登録マスタ件数  | その分類に属するマスタの件数                 |
| （見出しなし） | マスタ分類詳細画面へ遷移する「詳細」リンク          |

一覧仕様は以下とする。

- サーバー側で並び替えおよびページングを行う。検索条件は設けない。
- 1ページの表示件数は既存の `env.PAGE_SIZE` を使用する。
- 初期の並び順はマスタ分類コード（`MasterCategory.code`）の文字列昇順とする。
- 「マスタ分類コード」「マスタ分類名」「登録マスタ件数」の見出しを選択すると、一覧全体をその列で昇順に並べ替える。同じ見出しを再度選択すると降順へ切り替える。
- ソート列はURLクエリの`sort`（`code` / `name` / `masterCount`）、方向は`order`（`asc` / `desc`）へ保持する。列を切り替えた場合は昇順とし、ページ番号を1へ戻す。
- 末尾の詳細リンク列はソート対象外とし、見出しに「操作」は表示しない。
- 一覧の上部に総件数と現在のページを表示する。
- マスタ分類が0件の場合は「登録されているマスタ分類がありません」と表示する。
- 一覧は `@/shared/ui/table` のTableコンポーネントを使用する。

登録マスタ件数を表示することで、そのマスタ分類を削除できるかどうか（§24.1 の削除条件を満たすか）を詳細画面へ入る前に判断できる。

### 20.1.2 ボタン

| ボタン      | 動作                                             |
| -------- | ---------------------------------------------- |
| 新規登録     | マスタ分類新規登録画面（MST-08）へ遷移する。ADMINとOPERATORだけに表示する |
| マスタ一覧へ戻る | マスタ検索一覧画面（MST-01）へ戻る                           |
| CSVダウンロード | マスタ分類の全件をCSVでダウンロードする。全ロールに表示する → §30.1            |

「新規登録」ボタンは一覧領域の右上に配置する。**マスタ分類を登録できるのはこの導線だけ**とし、マスタ新規登録画面（MST-02）からは登録できない。
