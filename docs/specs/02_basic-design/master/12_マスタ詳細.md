## 12.1 マスタ詳細画面（MST-04）

### 12.1.1 表示項目

| 項目     | 表示内容                            |
| ------ | ------------------------------- |
| マスタ分類  | マスタ分類名                          |
| マスタコード | マスタコード                          |
| マスタ内容  | マスタ内容                           |
| 登録日時   | マスタを登録した日時                      |
| 登録者    | マスタを登録した利用者のユーザーID。不明な場合は「—」    |
| 最終更新日時 | マスタを最後に更新した日時                   |
| 最終更新者  | マスタを最後に更新した利用者のユーザーID。不明な場合は「—」 |

登録者・最終更新者は `createdBy` / `updatedBy`（§01.1.2）を表示する。これらは任意項目であり、値が無い場合は「—」を表示する。

### 12.1.2 ボタン

| ボタン   | 動作                                            |
| ----- | --------------------------------------------- |
| 一覧へ戻る | 元の検索条件を復元したマスタ検索一覧画面へ戻る                       |
| 更新する  | マスタ更新画面（MST-05）へ遷移する。ADMINとOPERATORだけに表示する    |
| 削除    | マスタ削除確認ダイアログ（§14.1）を表示する。ADMINとOPERATORだけに表示する |

「削除」ボタンは `variant="destructive"` とし、「更新する」ボタンから十分な間隔を空けて配置する。

URLで指定されたマスタIDに対応するマスタが存在しない場合は、404画面を表示する。削除済みのマスタは物理削除によりデータベースに存在しないため、削除後にそのURLへアクセスした場合も同じく404画面となる。マスタ更新画面（MST-05）も同様とする。
