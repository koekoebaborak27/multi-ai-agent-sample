# マスタ管理機能 基本設計書

マスタとマスタ分類の検索・登録・更新・削除と、CSV ダウンロードの基本設計。

## ファイルの分け方

**機能ごとに 1 ファイル。** 実装は 1 機能ずつ進めるため、その機能の画面・入力検証・同時実行制御・テスト方針が 1 ファイルに揃うようにしている。
分割前は章ごと（画面設計・入力検証・…）にまとまっていたため、1 機能を作るのに複数の章を行き来する必要があった。

**章番号は分割前から変えていない。** `§6.4` のような既存の参照はそのまま通用する。

| ファイル | 内容 |
|---|---|
| [`00_共通.md`](00_共通.md) | マスタ管理機能の前提。全機能に共通する概要・用語・権限・画面一覧・画面遷移・エラー設計・モジュール構成・対象外。**最初に読む。** |
| [`01_データベース.md`](01_データベース.md) | ER 概要・Prisma モデル・制約・マスタを参照するテーブルの扱い。全機能が参照する。 |
| [`10_マスタ検索一覧.md`](10_マスタ検索一覧.md) | 分類・コード・内容による検索、ページング、ソート。 |
| [`11_マスタ新規登録.md`](11_マスタ新規登録.md) | 登録フォームと確認画面、入力検証、登録時の重複制御。**確認画面（MST-03）の仕様はここが正本**で、更新（MST-05）からも使う。 |
| [`12_マスタ詳細.md`](12_マスタ詳細.md) | 1 件のマスタの表示と、更新・削除への導線。 |
| [`13_マスタ更新.md`](13_マスタ更新.md) | 更新フォームと楽観ロック。確認画面（MST-03）は [`11_マスタ新規登録.md`](11_マスタ新規登録.md#63-マスタ確認画面mst-03)、入力検証は [同 §7](11_マスタ新規登録.md#71-マスタ分類の選択mst-02mst-05) を参照する。 |
| [`14_マスタ削除.md`](14_マスタ削除.md) | 削除確認ダイアログ、削除時の競合、削除の記録。物理削除である理由は [`01_データベース.md`](01_データベース.md#83-制約) を参照する。 |
| [`20_マスタ分類一覧.md`](20_マスタ分類一覧.md) | 分類の一覧表示（採番順・ページング）。 |
| [`21_マスタ分類詳細.md`](21_マスタ分類詳細.md) | 1 件の分類の表示と、更新・削除への導線。 |
| [`22_マスタ分類新規登録.md`](22_マスタ分類新規登録.md) | 分類の登録フォームと確認画面、分類名の検証。**確認画面（MST-09）とテスト方針はここが正本**で、更新（MST-10）からも使う。 |
| [`23_マスタ分類更新.md`](23_マスタ分類更新.md) | 分類名の変更。確認画面（MST-09）は [`22_マスタ分類新規登録.md`](22_マスタ分類新規登録.md#610-マスタ分類確認画面mst-09)、分類名の検証は [同 §7.4](22_マスタ分類新規登録.md#74-マスタ分類名mst-08mst-10)、テスト方針は [同 §12.7](22_マスタ分類新規登録.md#127-マスタ分類の登録と更新) を参照する。 |
| [`30_CSVダウンロード.md`](30_CSVダウンロード.md) | 非同期の CSV 生成。出力仕様・処理の流れ・データモデル・worker の実行方式と本番構成・件数上限・保持と削除。 |
