# マスタ管理機能 基本設計書

マスタとマスタ分類の検索・登録・更新・削除と、CSV ダウンロードの基本設計。

## ファイルの分け方

**機能ごとに 1 ファイル。** 実装は 1 機能ずつ進めるため、その機能の画面・入力検証・同時実行制御・テスト方針が 1 ファイルに揃うようにしている。
分割前は章ごと（画面設計・入力検証・…）にまとまっていたため、1 機能を作るのに複数の章を行き来する必要があった。

**見出し番号はファイル名の連番と揃えている。** 各ファイルの見出しは、そのファイル名の連番（`00`・`01`・`10`〜`14`・`20`〜`24`・`30`）を先頭に持つ。他ファイルの節を指す `§10.1` のような参照は、対象ファイルの見出し番号を表す。
