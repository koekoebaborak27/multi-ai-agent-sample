## 23.1 マスタ分類更新画面（MST-10）

マスタ分類詳細画面（MST-07）の「更新する」ボタンから遷移する。この画面が変更するのは**マスタ分類そのものの名称**であり、個々のマスタの所属分類ではない。所属分類の変更はマスタ更新画面（§13.1）で行う。

### 23.1.1 表示・入力項目

| 項目       | UI部品     | 編集可否 | 入力仕様                                                  |
| -------- | -------- |:----:| ------------------------------------------------------- |
| マスタ分類コード | テキストボックス | 可    | 必須。1文字以上50文字以内。英大文字、数字、ハイフン、アンダースコアだけを許可する。初期値は現在の分類コード |
| マスタ分類名   | テキストボックス | 可    | 必須。1文字以上30文字以内。初期値は現在の分類名                               |
| 登録マスタ件数  | テキスト表示   | 不可   | その分類に属するマスタの件数を表示する                                    |

この画面で更新できる項目はマスタ分類コードとマスタ分類名の2つである。分類コードの検証ルールは §22.3.2、変更時の注意点（契約先分類・契約分類のコードを変更した場合の影響）は §22.2.4 を参照する。

### 23.1.2 ボタン

| ボタン   | 動作                                                |
| ----- | ------------------------------------------------- |
| 確認する  | 入力内容を検証し、問題がなければマスタ分類確認画面へ更新モードで進む。データベースの更新は行わない |
| キャンセル | 入力内容を破棄し、対象マスタ分類の詳細画面へ戻る                          |
