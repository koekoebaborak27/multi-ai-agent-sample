## 6.8 マスタ分類詳細画面（MST-07）

### 6.8.1 表示項目

| 項目       | 表示内容                           |
| -------- | ------------------------------ |
| マスタ分類コード | `MasterCategory.id` を4桁ゼロ埋めした値 |
| マスタ分類名   | マスタ分類名                         |
| 登録マスタ件数  | その分類に属するマスタの件数                 |
| 登録日時     | マスタ分類を登録した日時                   |
| 登録者      | 登録した利用者のユーザーID。不明な場合は「—」       |
| 最終更新日時   | マスタ分類を最後に更新した日時                |
| 最終更新者    | 最後に更新した利用者のユーザーID。不明な場合は「—」    |

### 6.8.2 ボタン

| ボタン   | 動作                                                |
| ----- | ------------------------------------------------- |
| 一覧へ戻る | マスタ分類一覧画面へ戻る                                      |
| 更新する  | マスタ分類更新画面（MST-10）へ遷移する。ADMINとOPERATORだけに表示する      |
| 削除    | マスタ分類削除確認ダイアログ（§6.8.4）を表示する。ADMINとOPERATORだけに表示する |

URLで指定されたマスタ分類IDに対応する分類が存在しない場合は、404画面を表示する。マスタ分類更新画面（MST-10）も同様とする。

### 6.8.3 削除条件

マスタ分類は、**そのマスタ分類に属するマスタが1件も存在しない場合にだけ**削除できる。

- 配下のマスタを一括削除する方式は採用しない。
- 配下にマスタが存在する場合は、先に個々のマスタを削除する必要がある。

配下にマスタが存在する場合、「削除」ボタンは表示するが、押下時に削除できない旨のエラーメッセージ（`MASTER_CATEGORY_HAS_MASTERS`）を表示する。件数は §6.8.1 に表示されているため、利用者は事前に削除可否を把握できる。

### 6.8.4 マスタ分類削除確認ダイアログ

| 項目       | 表示内容                 |
| -------- | -------------------- |
| 見出し      | 「マスタ分類を削除しますか？」      |
| マスタ分類コード | 削除対象のマスタ分類コード        |
| マスタ分類名   | 削除対象のマスタ分類名          |
| 警告       | 「削除したマスタ分類は元に戻せません。」 |
| ボタン      | 「キャンセル」および「削除する」     |

ダイアログの実装仕様（`AlertDialog` の使用、二重送信防止、フォーカス制御）は §6.6.2 と同一とする。

### 6.8.5 削除の実行処理

1. Server Actionで書き込み権限を検証する。
2. 対象マスタ分類が現在も存在することを確認する。
3. 詳細画面を表示した時点の `updatedAt` と、データベースに保存されている現在の `updatedAt` を比較する。
4. 対象マスタ分類に属するマスタが0件であることを確認する。
5. 対象マスタ分類を物理削除する。
6. マスタ分類一覧画面へ遷移し、削除完了メッセージを表示する。

配下マスタの件数確認と削除は、同じデータベーストランザクション内で行う。ただしPostgreSQLの既定の分離レベル（READ COMMITTED）では、件数確認から削除までの間に別の利用者が同じマスタ分類へマスタを登録する可能性を排除できない。

配下にマスタが残ったまま分類が削除されないことは、最終的には `Master.categoryId` の外部キー制約が保証する。マスタ分類の削除で外部キー制約違反が発生した場合は業務エラーへ変換し、`MASTER_CATEGORY_HAS_MASTERS` として扱う。アプリケーションによる件数確認は、利用者へ件数を伝えるための事前確認と位置づける（§9.1 の登録時の重複と同じ考え方）。

削除完了メッセージの表示方法は §6.6.4 と同じとし、リダイレクト先を `/master/categories?deleted=1` とする。
