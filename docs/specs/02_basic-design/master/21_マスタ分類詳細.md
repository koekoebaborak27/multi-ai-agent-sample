## 21.1 マスタ分類詳細画面（MST-07）

### 21.1.1 表示項目

| 項目       | 表示内容                           |
| -------- | ------------------------------ |
| マスタ分類コード | `MasterCategory.code` |
| マスタ分類名   | マスタ分類名                         |
| 登録マスタ件数  | その分類に属するマスタの件数                 |
| 登録日時     | マスタ分類を登録した日時                   |
| 登録者      | 登録した利用者のユーザーID。不明な場合は「—」       |
| 最終更新日時   | マスタ分類を最後に更新した日時                |
| 最終更新者    | 最後に更新した利用者のユーザーID。不明な場合は「—」    |

### 21.1.2 ボタン

| ボタン   | 動作                                                |
| ----- | ------------------------------------------------- |
| 一覧へ戻る | マスタ分類一覧画面へ戻る                                      |
| 更新する  | マスタ分類更新画面（MST-10）へ遷移する。ADMINとOPERATORだけに表示する      |
| 削除    | マスタ分類削除確認ダイアログ（[§24.2](24_マスタ分類削除.md#242-マスタ分類削除確認ダイアログ)）を表示する。ADMINとOPERATORだけに表示する |

URLで指定されたマスタ分類IDに対応する分類が存在しない場合は、404画面を表示する。マスタ分類更新画面（MST-10）も同様とする。

削除条件・削除確認ダイアログ・削除の実行処理は [`24_マスタ分類削除.md`](24_マスタ分類削除.md) を見ること。
