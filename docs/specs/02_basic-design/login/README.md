# ログイン機能 基本設計書

ログイン画面と、それに付随する初回パスワード変更誘導の基本設計。

要件は [`docs/specs/01_requirements/login/01_ログイン.md`](../../01_requirements/login/01_ログイン.md)。実装は`src/app/(auth)/login/`・`src/modules/auth/`・`src/proxy.ts`。

## ファイルの分け方

**画面ごとに1ファイル。** データベース変更は伴わない（既存の`User`モデルをそのまま使う）ため、データベース専用のファイルは作らない。

| ファイル | 内容 |
|---|---|
| [`10_ログイン画面.md`](10_ログイン画面.md) | ログイン画面（LGN-01）。ID・パスワード認証、Microsoft Entra ID 認証、ログイン失敗・ロック、セッション、ルートガード。 |
| [`11_初回パスワード変更画面.md`](11_初回パスワード変更画面.md) | パスワード変更画面（LGN-02）。初回ログイン時の強制誘導と、任意タイミングでの自主変更の両方を扱う。 |
