# パスワードリセット機能 基本設計書

ログイン画面から利用者が自分でパスワードを設定し直せるようにする機能の基本設計。あわせて、その前提となるメールアドレスの登録・変更と、メールを送る仕組みを扱う。

要件は [`docs/specs/01_requirements/password-reset/01_パスワードリセット.md`](../../01_requirements/password-reset/01_パスワードリセット.md)、残タスクは [`docs/todo/TODO.md`](../../../todo/TODO.md#パスワード再発行機能)。決定の経緯は [`docs/todo/history/2026-08-w3.md`](../../../todo/history/2026-08-w3.md) にある。

## ファイルの分け方

マスタ管理機能・契約先契約管理機能の設計書と同じく、**機能ごとに1ファイル**。見出し番号はファイル名の連番と揃えている。

| ファイル | 内容 |
|---|---|
| [`00_パスワードリセット共通.md`](00_パスワードリセット共通.md) | 前提。概要・用語・権限・画面一覧・画面遷移・エラー設計・モジュール構成・テスト方針・対象外。**最初に読む。** |
| [`01_データベース.md`](01_データベース.md) | `User.email` の変更、再設定用URL・メール変更申し込みの記録テーブル、合言葉の保存方法、マイグレーション手順。 |
| [`02_メール送信.md`](02_メール送信.md) | メールを送る共通の仕組み（Resend）、設定、4種類のメールの文面、失敗したときの扱い。**文面の正本はここ。** |
| [`10_再発行申請.md`](10_再発行申請.md) | 申請画面（PWR-01）、送信回数の制限、ログイン画面へのリンク追加。 |
| [`11_パスワード再設定.md`](11_パスワード再設定.md) | 再設定画面（PWR-02）、URLの確認、確定時の処理（ロック解除を含む）。 |
| [`20_メールアドレス管理.md`](20_メールアドレス管理.md) | 管理者による登録・変更、本人による変更（EML-01）と確認（EML-02）、重複の扱い。 |
