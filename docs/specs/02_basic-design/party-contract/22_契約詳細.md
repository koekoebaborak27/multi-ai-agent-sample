# 契約詳細（CTR-04）

1件の契約の表示と、更新・削除への導線。

契約先・契約管理機能 基本設計書の一部。全体の索引は [`README.md`](README.md)、共通の前提は [`00_契約先契約管理共通.md`](00_契約先契約管理共通.md) を見ること。

## 22.1 契約詳細画面（CTR-04）

### 22.1.1 表示項目

| 項目     | 表示内容                                    |
| ------ | --------------------------------------- |
| 契約名    | 契約名                                     |
| 契約先    | 契約先名称。契約先詳細画面（PTY-04）へのリンクとする            |
| 開始日    | 開始日。未定の場合は「未定」                          |
| 終了日    | 終了日。未定の場合は「未定」                          |
| 状態     | 状態の表示ラベル（下書き／有効／終了）                      |
| 契約分類   | 契約分類名。未設定・削除済みの場合は「未設定」                 |
| 登録日時   | 契約を登録した日時                               |
| 登録者    | 契約を登録した利用者のユーザーID。不明な場合は「—」              |
| 最終更新日時 | 契約を最後に更新した日時                            |
| 最終更新者  | 契約を最後に更新した利用者のユーザーID。不明な場合は「—」           |

登録者・最終更新者は `createdBy` / `updatedBy`（§01.1.2、新規追加カラム）を表示する。契約先へのリンクは§00.5のとおり、この画面からだけ張る（逆方向は張らない）。

### 22.1.2 ボタン

| ボタン   | 動作                                          |
| ----- | ------------------------------------------- |
| 一覧へ戻る | 元の検索条件を復元した契約検索一覧画面へ戻る                      |
| 編集する  | 契約更新画面（CTR-05）へ遷移する。ADMINとOPERATORだけに表示する    |
| 削除    | 契約削除確認ダイアログ（§24.1）を表示する。ADMINとOPERATORだけに表示する |

「削除」ボタンは `variant="destructive"` とし、「編集する」ボタンから十分な間隔を空けて配置する。

URLで指定された契約IDに対応する契約が存在しない場合は、404画面を表示する。削除済みの契約は物理削除によりデータベースに存在しないため、削除後にそのURLへアクセスした場合も同じく404画面となる。契約更新画面（CTR-05）も同様とする。
