# 契約先・契約管理機能 基本設計書

契約先（取引先）と契約の検索・登録・更新・削除の基本設計。

マスタ管理機能（[`docs/specs/02_basic-design/master/`](../master/README.md)）と同じ画面構成（検索一覧→詳細→編集/新規登録は別ページ→削除）に揃える。要件定義の経緯は [`docs/todo/history/2026-08-w3.md`](../../../todo/history/2026-08-w3.md#2026-08-19-契約先契約の管理画面整備の要件定義を実施) を参照。

## ファイルの分け方

マスタ管理機能の設計書と同じく、**機能ごとに1ファイル**。見出し番号はファイル名の連番と揃えている。契約先は `10`〜`14`、契約は `20`〜`24` を使う（マスタ管理機能の `10`〜`14`／`20`〜`24` と同じ番号割りだが、対象がマスタ分類ではなく契約という別モジュールである点が異なる）。

| ファイル | 内容 |
|---|---|
| [`00_契約先契約管理共通.md`](00_契約先契約管理共通.md) | 前提。概要・用語・権限・画面一覧・画面遷移・エラー設計・モジュール構成・対象外。**最初に読む。** |
| [`01_データベース.md`](01_データベース.md) | ER概要・Prismaモデルの変更点・制約。全機能が参照する。 |
| [`10_契約先検索一覧.md`](10_契約先検索一覧.md) | 名称・分類による検索、ページング、ソート。 |
| [`11_契約先新規登録.md`](11_契約先新規登録.md) | 登録フォームと確認画面、入力検証。**確認画面（PTY-03）の仕様はここが正本**で、更新（PTY-05）からも使う。 |
| [`12_契約先詳細.md`](12_契約先詳細.md) | 1件の契約先の表示と、更新・削除への導線。 |
| [`13_契約先更新.md`](13_契約先更新.md) | 更新フォームと楽観ロック。 |
| [`14_契約先削除.md`](14_契約先削除.md) | 削除確認ダイアログ、削除条件（紐づく契約が無いこと）、削除時の競合。 |
| [`20_契約検索一覧.md`](20_契約検索一覧.md) | 契約先・状態・分類による検索、ページング、ソート。 |
| [`21_契約新規登録.md`](21_契約新規登録.md) | 登録フォームと確認画面、入力検証。**確認画面（CTR-03）の仕様はここが正本**で、更新（CTR-05）からも使う。 |
| [`22_契約詳細.md`](22_契約詳細.md) | 1件の契約の表示と、更新・削除への導線。 |
| [`23_契約更新.md`](23_契約更新.md) | 更新フォームと楽観ロック。 |
| [`24_契約削除.md`](24_契約削除.md) | 削除確認ダイアログ、削除時の競合。 |
