## 10.1 契約先検索一覧画面（PTY-01）

### 10.1.1 検索条件の開閉

検索条件は `<SearchConditionCard>`（`@/shared/ui/search-condition-card`）で囲む。開閉仕様はマスタ検索一覧と同じ（[`master/10_マスタ検索一覧.md` §10.1.2](../master/10_マスタ検索一覧.md#1012-検索条件の開閉)）ため、ここでは繰り返さない。`DESIGN.md` §7「検索条件」も参照。

### 10.1.2 検索条件

| 項目   | UI部品     | 必須 | 説明                                   |
| ---- | -------- |:--:| ------------------------------------ |
| 名称   | テキストボックス | 任意 | 契約先名称の部分一致で検索する                     |
| 契約先分類 | プルダウン    | 任意 | 契約先分類（マスタ分類コード `CONTRACT_COMPANY_TYPE`）配下のマスタから1件を選択する。「すべて」を選択した場合は全分類を対象とする |

契約先分類は契約先ごとの**任意入力項目**であり（`Party.companyTypeMasterId` は `NULL` を許容する）、マスタ検索一覧のマスタ分類のように必ずどれかに属するわけではない。そのため**初期値は「すべて」とする**（マスタ検索一覧のような「登録済み分類の先頭」を初期値にする方式は採らない。未分類の契約先が初期表示から漏れてしまうため）。

検索条件はURLクエリとして保持する。

```text
/parties?keyword={契約先名称}&companyTypeId={マスタIDまたはall}&sort={ソート列}&order={ascまたはdesc}&page={ページ番号}
```

`companyTypeId=all` は「すべて」を選択した状態（既定値）を表す。

### 10.1.3 検索仕様

- 名称の前後にある空白は検索前に除去する。
- 名称は、大文字・小文字を区別しない部分一致検索を行う（PostgreSQLの `contains` 条件、マスタ検索一覧と同じ方式）。
- 契約先分類が指定された場合は、指定された分類に属する契約先だけを対象とする。
- 名称と契約先分類の両方が指定された場合はAND条件とする。
- 検索条件を変更して検索した場合、ページ番号を1へ戻す。

### 10.1.4 ボタン

| ボタン    | 動作                                        |
| ------ | ----------------------------------------- |
| 検索     | 入力された検索条件で検索し、ページ番号を1へ戻す                  |
| 条件をクリア | 検索条件、ソート条件およびページ番号を初期状態（名称空・分類「すべて」）へ戻す    |
| 新規登録   | 契約先新規登録画面（PTY-02）へ遷移する。ADMINとOPERATORだけに表示する |

一覧領域の右上に「新規登録」ボタンを配置する（マスタ検索一覧と同じ配置）。

### 10.1.5 一覧

| 列    | 表示内容                    |
| ---- | ----------------------- |
| 名称   | 契約先名称                   |
| 分類   | 契約先分類名。未設定・削除済みの場合は「未設定」 |
| 連絡先  | 連絡先。未入力の場合は「-」          |
| （見出しなし） | 契約先詳細画面へ遷移する「詳細」リンク    |

一覧仕様は以下とする（既存の `PartyTable` の並び替え・ページングを踏襲し、検索絞り込みを追加する）。

- サーバー側で検索、並び替えおよびページングを行う。
- 1ページの表示件数は既存の `env.PAGE_SIZE` を使用する。
- 初期の並び順は名称の昇順（既存の `PartySortField` の初期値と同じ）。
- 見出しによる並び替えは既存のとおり `name`・`contactInfo` の2列のみ（分類は表示専用の解決値のためソート対象外。既存のまま変更しない）。
- 末尾の詳細リンク列はソート対象外とする。
- 一覧の上部に検索結果の総件数と現在のページを表示する。
- 検索結果が0件の場合は「該当する契約先がありません」と表示する。
- 一覧は `@/shared/ui/table` のTableコンポーネントを使用する。
- **一覧に削除ボタンは置かない**（§00.4）。行の操作は「詳細」リンクのみとする。既存の `PartyTable` に埋め込まれている削除ボタン（`deletePartyAction` の呼び出し）はこの変更で撤去する。

### 10.1.6 テスト方針

- 名称キーワードで部分一致検索できる。
- 契約先分類で絞り込める。
- 名称と契約先分類のAND条件で絞り込める。
- 検索条件を指定しない場合に全件が対象になる（契約先分類が未設定の契約先も含む）。
- 検索結果が `env.PAGE_SIZE` 件でページングされる。
- 名称の昇順・降順で並び替えられる。
- 検索条件を変更するとページ番号が1へ戻る。
- 「条件をクリア」で名称空・分類「すべて」・ページ1へ戻る。
- VIEWERでも一覧を参照できるが、「新規登録」ボタンは表示されない。
