# 契約先詳細（PTY-04）

1件の契約先の表示と、更新・削除への導線。

契約先・契約管理機能 基本設計書の一部。全体の索引は [`README.md`](README.md)、共通の前提は [`00_契約先契約管理共通.md`](00_契約先契約管理共通.md) を見ること。

## 12.1 契約先詳細画面（PTY-04）

### 12.1.1 表示項目

| 項目     | 表示内容                          |
| ------ | ----------------------------- |
| 名称     | 契約先名称                         |
| 分類     | 契約先分類名。未設定・削除済みの場合は「未設定」      |
| 連絡先    | 連絡先。未入力の場合は「-」                |
| 登録日時   | 契約先を登録した日時                    |
| 登録者    | 契約先を登録した利用者のユーザーID。不明な場合は「—」  |
| 最終更新日時 | 契約先を最後に更新した日時                 |
| 最終更新者  | 契約先を最後に更新した利用者のユーザーID。不明な場合は「—」 |

登録者・最終更新者は `createdBy` / `updatedBy`（§01.1.2、新規追加カラム）を表示する。

**紐づく契約の一覧は表示しない**（要件定義で対象外と確定済み。§00.1）。

### 12.1.2 ボタン

| ボタン   | 動作                                            |
| ----- | --------------------------------------------- |
| 一覧へ戻る | 元の検索条件を復元した契約先検索一覧画面へ戻る                       |
| 編集する  | 契約先更新画面（PTY-05）へ遷移する。ADMINとOPERATORだけに表示する    |
| 削除    | 契約先削除確認ダイアログ（§14.2）を表示する。ADMINとOPERATORだけに表示する |

「削除」ボタンは `variant="destructive"` とし、「編集する」ボタンから十分な間隔を空けて配置する（マスタ詳細画面と同じ）。

URLで指定された契約先IDに対応する契約先が存在しない場合は、404画面を表示する。削除済みの契約先は物理削除によりデータベースに存在しないため、削除後にそのURLへアクセスした場合も同じく404画面となる。契約先更新画面（PTY-05）も同様とする。
