## 00.1 画面

ルートは `/`（`src/app/(main)/page.tsx`）。ログイン必須（未ログイン時の扱いは [`docs/specs/02_basic-design/login/10_ログイン画面.md` 10.7](../login/10_ログイン画面.md#107-ルートガード)を参照）。

| 要素 | 内容 |
|---|---|
| 見出し | 「トップ」 |
| お知らせカード | アイコン（`Megaphone`）＋見出し「お知らせ」のカード1つ。中身は`NewsFeed`コンポーネントに委ねる（→ [00.3](#003-お知らせカードとの関係)） |

ヘッダー・ナビゲーション等の共通レイアウトは`src/app/(main)/layout.tsx`が担い、この画面固有の設計対象ではない。

## 00.2 処理の流れ

1. サーバー側で`newsService.listPublished(0)`を呼び、公開中のお知らせの最初のページ（0ページ目）を取得する
2. 取得結果（`items`・`hasMore`）を`NewsFeed`へ初期値として渡す
3. ページは`export const dynamic = "force-dynamic"`により、リクエストのたびにサーバー側で作り直す（ログイン確認とデータベース取得を要するため、静的生成は使わない）

## 00.3 お知らせカードとの関係

お知らせの並び順・文字色分け・「さらに表示」による追加取得・0件時の表示など、カードの中身そのものの設計はお知らせ管理機能側で定義済み。この画面はそれを呼び出す入れ物でしかない。

詳細は [`docs/specs/02_basic-design/news/10_トップ画面お知らせ表示.md`](../news/10_トップ画面お知らせ表示.md) を参照。

## 00.4 モジュール構成

| ファイル | 役割 |
|---|---|

| `src/modules/news/ui/news-feed.tsx` | お知らせカードの中身（一覧表示・追加取得）。詳細はお知らせ管理機能の基本設計を参照 |
