# 8. 手順3 本番データベースを初期化する

手順3。マイグレーション適用と初期管理者の投入。

インフラ構築手順書の一部。全体の目次と進め方は [`README.md`](README.md) を見ること。


所要時間の目安: 20 分。

作成したばかりの Supabase データベースは空の状態です。**PC 上のコマンドから**、表を作り、最初の管理者ユーザーを登録します。

> **この手順の実行中は、本番データベースへ接続した状態になります。** 手順 6（ターミナルを閉じる）まで必ず実施してください。

## 8.1 コマンド履歴にパスワードを残さないようにする

PowerShell は既定で、実行したコマンドをすべてファイルへ保存します。本番のパスワードを扱うため、この機能をこのセッションだけ無効にします。

```powershell
Set-PSReadLineOption -HistorySaveStyle SaveNothing
```

## 8.2 接続先を設定する

[7.3](infra_design_03_Supabase作成.md#73-接続文字列を取得する) で作成した接続文字列を設定します。

```powershell
$env:DATABASE_URL='postgresql://postgres.<プロジェクトref>:<パスワード>@aws-0-us-east-1.pooler.supabase.com:5432/postgres'
```

> **引用符はシングルクォート（`'`）を使ってください。** PowerShell のダブルクォート（`"`）の中では `$` が変数として解釈され、パスワードに `$` が含まれていると別の文字列に置き換わってしまいます。

> **`.env` ファイルへ本番の接続文字列を書かないでください。** 書いた場合、以降のローカル開発（`pnpm dev`）が本番データベースへ接続してしまいます。上記のように `$env:` で設定すると、そのターミナルを閉じたときに消えます。

## 8.3 接続を確認する

データベースを変更しないコマンドで、接続できることを先に確認します。

```powershell
pnpm exec prisma migrate status
```

`1 migration has not yet been applied`（まだ適用されていない変更がある）のように表示されれば、接続は成功しています。

## 8.4 マイグレーションを適用する

```powershell
pnpm exec prisma migrate deploy
```

`All migrations have been successfully applied.` と表示されれば完了です。表が作成されました。

## 8.5 初期管理者を登録する

**手順 8.2 と同じターミナルで**実行してください。

```powershell
$env:SEED_ADMIN_PASSWORD='<推測されにくいパスワード>'
pnpm prisma:seed
```

`Seed 完了: 初期ADMIN(admin)` と表示されれば成功です。

| 項目      | 値                            |
| ------- | ---------------------------- |
| ログイン ID | `admin`                      |
| パスワード   | `SEED_ADMIN_PASSWORD` に指定した値 |

> **同じターミナルで実行する理由**: `pnpm prisma:seed` は `.env` ファイルを読まないため、手順 8.2 で設定した `DATABASE_URL` が同じターミナルに残っている必要があります。

> **このコマンドは、登録したパスワードを画面へそのまま表示します。** 画面共有中は注意してください。

### 注意: パスワードの再設定は seed ではできない

[`prisma/seed.ts`](../../../prisma/seed.ts) は「ユーザーが既に存在する場合は何もしない」動作のため、**もう一度実行しても既存ユーザーのパスワードは変わりません。** パスワードが分からなくなった場合は、データベースを直接更新する必要があります。

## 8.6 ターミナルを閉じる

```powershell
exit
```

**この手順を省略しないでください。** `DATABASE_URL` が本番を指したままのターミナルで `pnpm dev` を実行すると、開発サーバーが本番データベースへ接続します。
