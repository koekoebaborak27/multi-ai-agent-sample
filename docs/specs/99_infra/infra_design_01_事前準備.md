# 01.1 事前準備

用意するアカウント・ツールと、作業中に控えておく情報。

インフラ構築手順書の一部。全体の目次と進め方は [`README.md`](README.md) を見ること。


## 01.1.1 用意するアカウント

| サービス         | 必要なもの                | 備考                        |
| ------------ | -------------------- | ------------------------- |
| GitHub       | アカウント                | private リポジトリは無料で作成できます   |
| Supabase     | アカウント                | GitHub アカウントでのサインアップが手軽です |
| Google Cloud | アカウント + **クレジットカード** | 無料枠の範囲でも登録は必須です           |

> **クレジットカードの登録について**: Google Cloud は登録時にカード情報を求めますが、無料枠の範囲内であれば請求は発生しません。ただし設定を誤ると課金される可能性があるため、[05.1.4](infra_design_05_CloudRun構築.md#0514-サービスの設定値) の「インスタンスの最大数」を必ず設定してください。

## 01.1.2 用意するツール

PC 側で使うツールです。[`README.md`](../../../README.md#1-必要なソフトウェアをインストールする) の手順で導入済みであれば、追加の作業は不要です。

| ツール               | 用途                                                                                               | 確認コマンド                              |
| ----------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------- |
| Git               | ソースコードの登録                                                                                        | `git --version`                     |
| GitHub CLI（`gh`）  | GitHub の操作をコマンドで行う                                                                               | `gh --version`                      |
| Node.js 22 / pnpm | マイグレーション・seed の実行                                                                                | `node --version` / `pnpm --version` |
| Docker Desktop    | 事前のローカル確認（任意）／手順6で worker 用イメージを作るとき（必須）                                                         | `docker --version`                  |
| gcloud CLI        | 手順6で worker 用イメージを Google Cloud へ登録するとき（**worker を使う機能（CSVダウンロードやアップロードなど時間がかかる機能）を採用する場合のみ必須**） | `gcloud --version`                  |

GitHub CLI を導入していない場合は [GitHub CLI](https://cli.github.com/) からインストールし、次のコマンドで認証します。

```powershell
gh auth login
```

gcloud CLI を導入していない場合は [Google Cloud CLI のインストール手順](https://cloud.google.com/sdk/docs/install) からインストールし、次のコマンドでログインします（初回のみ）。**手順6（[`infra_design_07_CloudRunJobs構築.md`](infra_design_07_CloudRunJobs構築.md)）に進むまでは不要です。**

```powershell
gcloud init
```

> ここまでの手順1〜5（GitHub リポジトリ作成 〜 Cloud Run の動作確認）は、すべてブラウザの Google Cloud コンソール上の操作だけで完結します。gcloud CLI が必要になるのは、手順6で worker 用のコンテナイメージを**お使いの PC 上で**手動ビルドするときだけです。

## 01.1.3 作業中に控えておく情報

構築の過程で次の値が確定します。**メモ帳などに控えながら進めてください。** 後の手順で使います。

| #   | 値                            | 決まる場所 | 使う場所                 |
| --- | ---------------------------- | ----- | -------------------- |
| 1   | GitHub リポジトリ名                | 手順 1  | 手順 4（Cloud Run との連携） |
| 2   | Supabase のデータベースパスワード        | 手順 2  | 手順 2・3・4             |
| 3   | Supabase の接続文字列              | 手順 2  | 手順 3・4               |
| 4   | Supabase の URL と `secret` キー | 手順 2  | 手順 4                 |
| 5   | 初期管理者のパスワード                  | 手順 3  | 手順 5（初回ログイン）         |
| 6   | Cloud Run のエンドポイント URL       | 手順 4  | 手順 4（環境変数）・手順 5      |

> **パスワードやキーの取り扱い**: これらは**リポジトリへ登録しないでください**。`.env` ファイルは [`.gitignore`](../../../.gitignore) により Git の管理対象外になっていますが、それ以外の場所へ書き込まないよう注意してください。
