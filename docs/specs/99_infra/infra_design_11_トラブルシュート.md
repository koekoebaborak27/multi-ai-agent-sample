# 11.1 トラブルシュート

症状から原因と対処を引く一覧。

インフラ構築手順書の一部。全体の目次と進め方は [`README.md`](README.md) を見ること。


## 11.1.1 ビルド・デプロイの問題

| 症状                                                                 | 原因                                               | 対処                                                                                    |
| ------------------------------------------------------------------ | ------------------------------------------------ | ------------------------------------------------------------------------------------- |
| ビルドが 10 秒程度で失敗し、`Permission 'developerconnect.gitRepos...'` と表示される | GitHub からソースを取得する権限が不足している                       | トリガー編集画面の「すべて付与」を押す。権限の反映には時間差があるため、再実行で解決する場合もある（[05.1.6](infra_design_05_CloudRun構築.md#0516-cloud-build-のビルド設定を修正する)） |
| `COPY failed: ... stat package.json: file does not exist`          | ビルドの起点が `docker/` になっている                         | ビルド設定の起点を `.`（リポジトリ全体）に変更する（[05.1.6](infra_design_05_CloudRun構築.md#0516-cloud-build-のビルド設定を修正する)）                       |
| ビルド設定を直したのに、同じ場所で同じように失敗する                                         | 「ビルドを再試行」を使っている                                  | 「再試行」は修正前の設定を使い直す。**Cloud Build → トリガー → 「実行」**から実行する                                 |
| ビルドが制限時間で打ち切られる                                                    | 既定の制限時間（10 分）を超えた                                | ビルド設定に `timeout: 1800s` を追加する                                                         |
| `main` へ push したのにデプロイされない                                         | トリガーの対象ブランチが違う、またはコミットメッセージに `[skip ci]` が含まれている | Cloud Build のトリガー設定を確認する                                                              |

## 11.1.2 起動・接続の問題

| 症状                                                | 原因                                        | 対処                                                                                 |
| ------------------------------------------------- | ----------------------------------------- | ---------------------------------------------------------------------------------- |
| コンテナが起動せず、ログに `環境変数の検証に失敗しました:` と出る               | 必須の環境変数が不足している                            | 表示された変数名を Cloud Run の環境変数へ追加する（[05.1.5](infra_design_05_CloudRun構築.md#0515-環境変数を設定する)）                               |
| `/api/health` は成功するが `/api/health?check=db` が失敗する | データベースへ接続できていない                           | 接続文字列が **Session pooler**（ポート 5432・ホスト名に `pooler` を含む）か確認する（[03.1.3](infra_design_03_Supabase作成.md#0313-接続文字列を取得する)） |
| データベースへの接続がタイムアウトする                               | Direct connection の接続文字列を使っている            | Session pooler へ変更する。Direct connection は Cloud Run から到達できない                        |
| `prisma migrate deploy` が失敗する                     | Transaction pooler（ポート 6543）の接続文字列を使っている  | Session pooler（ポート 5432）へ変更する                                                      |
| 認証エラーで接続できない                                      | パスワードの置換漏れ、または PowerShell のダブルクォートによる変数展開 | `[YOUR-PASSWORD]` を角かっこごと置換し、**シングルクォート**で囲む（[04.1.2](infra_design_04_本番データベース初期化.md#0412-接続先を設定する)）                  |

## 11.1.3 画面・ログインの問題

| 症状                           | 原因                           | 対処                                                                                |
| ---------------------------- | ---------------------------- | --------------------------------------------------------------------------------- |
| アプリの画面ではなく Google のログイン画面が出る | サービスの認証設定が「認証が必要」になっている      | 「パブリック アクセスを許可」へ変更する（[05.1.4](infra_design_05_CloudRun構築.md#0514-サービスの設定値)）                                         |
| ログイン後にログイン画面へ戻り続ける           | `AUTH_URL` が実際の URL と一致していない | Cloud Run の環境変数を確認する。**末尾のスラッシュは付けない**                                            |
| ログインできず、失敗を繰り返した             | アカウントがロックされた（20 回で自動ロック）     | **自動では解除されません。** データベースの該当ユーザーの `lockedAt` を `null`、`failedAttempts` を `0` に戻す    |
| 初期管理者のパスワードが分からない            | seed の再実行では上書きできない           | データベースを直接更新する（[04.1.5](infra_design_04_本番データベース初期化.md#0415-初期管理者を登録する)）                                              |
| 画面のデザインが崩れている                | 静的ファイルが配信されていない              | ビルド設定で `--target runner` が指定されているか確認する                                            |
| ファイルの取得が失敗する                 | 非公開バケットに対して公開 URL を使っている     | `getSignedUrl` を使う（[`README.md`](../../../README.md#ブラウザへファイルを渡すurlgetsignedurl)） |

## 11.1.4 費用の問題

| 症状          | 原因                    | 対処                                                   |
| ----------- | --------------------- | ---------------------------------------------------- |
| 想定外の請求が発生した | インスタンスの最大数が既定（100）のまま | **`2` に設定する**（[05.1.4](infra_design_05_CloudRun構築.md#0514-サービスの設定値)）。リビジョンの編集で変更できる    |
| 無料枠の消費が早い   | メモリを 1GiB 以上に設定している   | 512MiB へ戻す。実測値は 77MB のため十分です                         |
| リージョンを間違えた  | 米国以外のリージョンで作成した       | 無料枠の対象外です。**サービスを作り直してください**（[00.4 章](infra_design_00_概要と全体構成.md#004-あとから変更できない項目)） |
