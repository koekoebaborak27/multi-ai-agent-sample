# 13.1 構築完了チェックリスト

構築の完了判定と、関連ドキュメントへの参照。

インフラ構築手順書の一部。全体の目次と進め方は [`README.md`](README.md) を見ること。


すべてにチェックが付けば、インフラ構築は完了です。

**GitHub**

- [ ] private リポジトリを作成し、ソースコードを push した
- [ ] `.env` がリポジトリへ登録されていないことを確認した
- [ ] GitHub Actions の CI が成功した

**Supabase**

- [ ] プロジェクトを **East US (North Virginia)** で作成した
- [ ] **Session pooler** の接続文字列を取得した（ポート 5432・ホスト名に `pooler` を含む）
- [ ] バケット `uploads` を **private** で作成した
- [ ] `secret` キーと URL を控えた

**本番データベース**

- [ ] `prisma migrate deploy` が成功した
- [ ] 初期管理者を登録した
- [ ] 作業に使ったターミナルを閉じた

**Google Cloud Run**

- [ ] リージョンが **`us-central1`** になっている
- [ ] 認証が **パブリック アクセスを許可** になっている
- [ ] **インスタンスの最大数が `2`** に設定されている
- [ ] 環境変数 9 個をすべて登録した
- [ ] ビルド設定の起点が `.`（リポジトリ全体）になっている
- [ ] ビルドとデプロイが成功した

**動作確認**

- [ ] `/api/health` が `status: ok` を返す（アプリが起動している）
- [ ] `/api/health?check=db` が `db: up` を返す（データベースへ接続できている）
- [ ] 初期管理者でログインできる（認証が動作している）
- [ ] パスワードを変更できる（データの更新ができている）
- [ ] 画面からデータを登録し、一覧に表示される（データの登録・参照ができている）
- [ ] `main` への push で自動デプロイされることを確認した

**構築後に検討する項目**

- [ ] `main` のブランチ保護を設定する（[02.1.6](infra_design_02_GitHubリポジトリ.md#0216-ブランチ保護を設定する)）
- [ ] Cloud Run のサービスアカウントを、権限を持たない専用のものへ差し替える（[05.1.4](infra_design_05_CloudRun構築.md#0514-サービスの設定値)）
- [ ] ドキュメントのみの変更でビルドを実行しない設定を入れるか決める（[09.1.1](infra_design_10_構築後の運用.md#1011-本番へ反映する)）
