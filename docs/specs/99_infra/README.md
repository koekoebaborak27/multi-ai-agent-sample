# インフラ構築手順書

このテンプレートを新しい案件へ流用し、**本番環境をゼロから構築する**ための手順書です。

本書では、GitHub / Supabase / Google Cloud Run を組み合わせた本番環境の構築作業を **「インフラ構築」** と呼びます。

## 読む順番

**手順ごとにファイルを分けています。** 上から順に進めてください。**07・08（Cloud Run Jobs）は、worker を使う機能を採用する案件のときだけ実施します。** 採用しない場合は読み飛ばして構いません。
**見出し番号はファイル名の連番と揃えている。** 各ファイルの見出しは、そのファイル名の連番（`00`〜`12`）を先頭に持つ。他ファイルの節を指す `§05.1` のような参照は、対象ファイルの見出し番号を表す。
