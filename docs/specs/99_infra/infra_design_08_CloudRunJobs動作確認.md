# 08.1 手順7 Cloud Run Jobs の動作を確認する

手順7（該当する場合のみ）。[`infra_design_07_CloudRunJobs構築.md`](infra_design_07_CloudRunJobs構築.md) で作成した worker（Cloud Run Jobs）の単体実行と、app と連携させた一連の動作を確認する。

インフラ構築手順書の一部。全体の目次と進め方は [`README.md`](README.md) を見ること。


所要時間の目安: 30 分。

> **前提**: worker が使う機能（マスタ機能の CSVダウンロード等）のテーブルまで、本番データベースへマイグレーションが適用済みであること（[09.1.2](infra_design_09_構築後の運用.md#0912-データベースの構造を変更する)）。適用されていない場合、worker はテーブルが無いというエラーで失敗します。

## 08.1.1 Jobs 単体を手動実行する

Cloud Run の **「ジョブ」** タブから対象のジョブ（例: `contract-worker`）を開き、**「実行」** を押します。

キューにジョブが無い状態でも、単発モード（`--once`）は数秒待ってから正常終了します（[`src/worker/index.ts`](../../../src/worker/index.ts)）。

## 08.1.2 ログを確認する

ジョブの実行詳細画面、または「実行」タブから該当の実行を開いてログを確認します。

| 確認内容 | 期待するログ | 失敗した場合 |
| --- | --- | --- |
| 起動できているか | `worker 起動完了: pg-boss ready（単発実行）` | 環境変数の検証に失敗しました: と出る場合、[07.1.4](infra_design_07_CloudRunJobs構築.md#0714-環境変数を設定する) の設定漏れ |
| キューが空で正常終了するか | `処理すべきジョブが無いため、worker を終了します` に続き、実行のステータスが成功（緑色）になる | ステータスが失敗（赤色）の場合、`DATABASE_URL` の接続文字列を確認する（[03.1.3](infra_design_03_Supabase作成.md#0313-接続文字列を取得する)） |

> 実行完了後のステータスコードが `0` であれば正常終了です。**Cloud Run Jobs はコンテナが終了しないといつまでも「実行中」のままになるため**、単発モード（`--once`）が正しく指定されているかは特に確認してください（[07.1.3](infra_design_07_CloudRunJobs構築.md#0713-cloud-run-jobs-を作成する)）。

## 08.1.3 app と連携させて確認する（依頼 → 生成 → 受け取り）

[07.1.5](infra_design_07_CloudRunJobs構築.md#0715-app-側に-worker-の起動先を設定する)・[07.1.6](infra_design_07_CloudRunJobs構築.md#0716-app-にジョブ実行権限を付与する) が完了している前提です。

1. ブラウザで本番の URL を開き、[04.1.5](infra_design_04_本番データベース初期化.md#0415-初期管理者を登録する) の管理者でログインする。
2. マスタ検索一覧（またはマスタ分類一覧）で「CSVダウンロード」を実行する（依頼）。
3. 状態が `READY` に変わるまで待つ（生成）。**app が起動要求を送ってから worker が処理を終えるまで、数秒〜十数秒かかります**（Cloud Run Jobs のコールドスタートを含むため）。
4. ダウンロードが成功し、CSV の内容が正しいことを確認する（受け取り）。

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 状態がずっと `QUEUED` のまま変わらない | app から worker への起動要求が失敗している（依頼自体は失敗しない設計。[`src/shared/jobs/invoke-worker.ts`](../../../src/shared/jobs/invoke-worker.ts)） | app のログで `worker起動要求に失敗しました` を探す。多くは [07.1.6](infra_design_07_CloudRunJobs構築.md#0716-app-にジョブ実行権限を付与する) の権限不足 |
| worker 側の実行ログにエラーが出ている | ストレージ関連の環境変数が未設定・誤り | [07.1.4](infra_design_07_CloudRunJobs構築.md#0714-環境変数を設定する) の `SUPABASE_*` 3項目を確認する |
| ダウンロードした CSV が空、または件数が想定と違う | 検索条件・データそのものの問題 | ローカルの動作と比較する（設計書 [`30_CSVダウンロード.md`](../02_basic-design/master/30_CSVダウンロード.md)） |

これらで解決しない場合は [11.1 トラブルシュート](infra_design_11_トラブルシュート.md#111-トラブルシュート) も参照してください。
