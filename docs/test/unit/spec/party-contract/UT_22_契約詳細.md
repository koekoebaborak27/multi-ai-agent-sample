# 単体テスト仕様書: 契約詳細（CTR-04）

## 1. テスト対象
- 対象機能: 契約詳細（CTR-04）
- 対象画面またはAPI: `/contracts/{contractId}`（契約詳細画面）
- 対象ファイル:
  - `src/app/(main)/contracts/[contractId]/page.tsx`
  - `src/modules/contract/ui/contract-detail-view.tsx`
  - `src/modules/contract/service.ts`（`findDetail`）
  - `src/modules/contract/repository.ts`（`findById`）
- 関連DBテーブル: `Contract`、`Party`、`MasterCategory`、`Master`
- 関連設計書: [`docs/specs/02_basic-design/party-contract/22_契約詳細.md`](../../../specs/02_basic-design/party-contract/22_契約詳細.md)

## 2. 前提条件
- 実行環境: ローカル環境（`pnpm dev` で起動した検証用サーバー。本番URL・本番DBには接続しない）
- ログインユーザー: ADMIN/OPERATORロール（「編集する」「削除」ボタンの表示確認）、VIEWERロール（TC-007の権限確認用）
- 権限: 詳細の参照は全ロールで可能。「編集する」「削除」ボタンの表示はADMIN/OPERATORに限る。
- 事前DB状態:
  - 契約先・開始日・終了日・契約分類・登録者・更新者が設定された契約が1件登録済み。
  - `createdBy`/`updatedBy` が `null` の契約を1件用意する（TC-003用。DBを直接操作して作成する）。
  - 開始日・終了日・契約分類が未設定の契約を1件用意する。
- 使用するテストデータ: 上記の契約ID

## 3. テスト観点
- 正常系: 表示項目の確認、契約先詳細画面へのリンク、登録・更新直後の完了メッセージ表示
- 異常系: 存在しない契約IDでの404表示
- 境界値: 該当なし
- 権限: VIEWERでの閲覧可・編集/削除ボタン非表示
- DB更新: 該当なし（参照のみの画面）
- 画面表示: 開始日/終了日未定時「未定」表示、契約分類未設定時「未設定」表示、登録者/更新者不明時「—」表示

## 7. 補足
- 本画面は参照専用のため、DB確認内容は全ケースで「該当なし」とした。
- 契約先詳細画面（PTY-04）からこの画面への逆方向のリンクは存在しない仕様（§00.5）のため、その非存在確認はTC-002の実施時に契約先詳細画面側で目視することで兼ねる。
- 削除済みの契約URLへアクセスした場合も404になる仕様だが、これは削除機能（`UT_24_契約削除.md`）のテストケースの一環として確認する。
