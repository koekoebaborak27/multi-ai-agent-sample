- 関連設計書: [`docs/specs/02_basic-design/master/10_マスタ検索一覧.md`](../../../specs/02_basic-design/master/10_マスタ検索一覧.md)

## 2. 前提条件
- 実行環境: ローカル環境（`pnpm dev` で起動した検証用サーバー。本番URL・本番DBには接続しない）
- ログインユーザー: ADMINロール、OPERATORロール、VIEWERロールの各ユーザーが必要（TC-009で使用）。OPERATOR/VIEWERロールのユーザーは `prisma/seed.ts` に用意されていないため、別途用意する。
- 権限: 本画面の閲覧自体はログインしていればロールを問わない。「新規登録」ボタンの表示のみADMIN/OPERATORロールに限定される（`canWrite`）。
- 事前DB状態:
  - マスタ分類（`MasterCategory`）が2件以上登録済み（分類名の昇順で並べたときの先頭と2番目が判別できること。以下「分類A」「分類B」とする）。
  - 分類Aに、マスタコードの値が異なるマスタ（`Master`）が3件以上登録済み。
  - 分類Aに属し、マスタコードまたはマスタ内容に「AB」を含むマスタ（例: マスタコード `AB01`）と、含まないマスタが両方登録済み。
  - `env.PAGE_SIZE`（既定30件）を超える件数のマスタが分類Aに登録済み（ページング確認用。31件以上）。
  - マスタコード・マスタ内容のいずれにも一致しない文字列（例:「ZZZZZZZZ」）に一致するマスタが存在しないこと。
- 使用するテストデータ:
  - 分類A（分類名昇順の先頭）、分類B（分類名昇順の2番目）
  - 分類Aに属するマスタ: マスタコード `AB01`（マスタ内容は任意）を含む3件以上、うち31件以上は分類Aに集約してページングを確認できる件数にする

## 3. テスト観点
- 正常系: マスタ分類・マスタ文字列による検索、AND条件での絞り込み、「すべて」を対象にした検索、部分一致・大文字小文字を区別しない検索
- 異常系: 検索結果が0件のときの表示
- 境界値: ページングの「前へ」「次へ」ボタンの活性・非活性が切り替わる境界、並び替えの昇順・降順の切り替え
- 権限: 「新規登録」ボタンの表示制御（ADMIN/OPERATORのみ表示）
- DB更新: なし（本画面は検索・表示のみで、DBを更新する操作を持たない）
- 画面表示: 検索条件の開閉、並び替え見出しの操作、ページング、CSVダウンロードボタンの非活性理由表示

## 7. 補足
- CSVダウンロードボタンは本画面（MST-01）にも表示されるが、実際のCSV生成処理（非同期ジョブ・ダウンロード完了）は別仕様書 [`docs/specs/02_basic-design/master/30_CSVダウンロード.md`](../../../specs/02_basic-design/master/30_CSVダウンロード.md) の管轄のため、本仕様書ではボタンの活性・非活性と非活性理由の表示（TC-010）までを対象とし、CSV生成・ダウンロード自体の検証は対象外とする。
- CSVダウンロードボタンが非活性になる条件は「検索結果0件」と「検索結果が上限（`MASTER_EXPORT_MAX_ROWS` = 10,000件）を超過」の2つだが、後者は10,000件超のテストデータ投入が現実的でないため本仕様書の対象外とした。
- テスト観点チェックリストのうち、以下は本画面の性質上対象外とした。
  - 最大文字数: マスタ文字列（検索キーワード）に文字数の上限チェックはないため対象外。
  - 重複: 本画面は登録操作を持たないため対象外。
  - 存在しないID: 本画面はIDをパラメータに取らない（詳細画面への遷移先の話であり、詳細画面側の仕様書で確認する）ため対象外。
  - DB制約違反: 本画面は読み取り専用のため対象外。
  - 未入力: マスタ分類・マスタ文字列はいずれも任意項目で、未入力時のエラーは発生しない。未入力状態での挙動はTC-001（初期表示）で確認している。
