# 単体テスト仕様書: 契約先詳細（PTY-04）

## 1. テスト対象
- 対象機能: 契約先詳細（PTY-04）
- 対象画面またはAPI: `/parties/{partyId}`（契約先詳細画面）
- 対象ファイル:
  - `src/app/(main)/parties/[partyId]/page.tsx`
  - `src/modules/party/ui/party-detail-view.tsx`
  - `src/modules/party/service.ts`（`findDetail`）
  - `src/modules/party/repository.ts`（`findById`）
- 関連DBテーブル: `Party`、`MasterCategory`、`Master`
- 関連設計書: [`docs/specs/02_basic-design/party-contract/12_契約先詳細.md`](../../../specs/02_basic-design/party-contract/12_契約先詳細.md)

## 2. 前提条件
- 実行環境: ローカル環境（`pnpm dev` で起動した検証用サーバー。本番URL・本番DBには接続しない）
- ログインユーザー: ADMIN/OPERATORロール（「編集する」「削除」ボタンの表示確認）、VIEWERロール（TC-006の権限確認用）
- 権限: 詳細の参照は全ロールで可能。「編集する」「削除」ボタンの表示はADMIN/OPERATORに限る。
- 事前DB状態:
  - 契約先分類・連絡先・登録者・更新者が設定された契約先が1件登録済み。
  - `createdBy`/`updatedBy` が `null` の契約先を1件用意する（TC-003の「不明時の表示」確認用。DBを直接操作して作成する）。
  - 契約先分類が未設定（`companyTypeMasterId = null`）の契約先を1件用意する。
- 使用するテストデータ: 上記の契約先ID

## 3. テスト観点
- 正常系: 表示項目の確認、登録・更新直後の完了メッセージ表示
- 異常系: 存在しない契約先IDでの404表示
- 境界値: 該当なし
- 権限: VIEWERでの閲覧可・編集/削除ボタン非表示
- DB更新: 該当なし（参照のみの画面）
- 画面表示: 分類未設定時「未設定」表示、登録者/更新者不明時「—」表示、紐づく契約一覧を表示しないこと
