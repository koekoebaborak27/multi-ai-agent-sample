# 単体テスト仕様書: セキュリティ横断テスト

## 1. テスト対象
- 対象機能: セキュリティ横断（XSS注入・SQLインジェクション風入力・セキュリティヘッダー）。公開用テンプレート切り出し前の確認であり、単一画面ではなく複数機能を横断する。
- 対象画面またはAPI: `/master`、`/master/new`、`/parties/new`、`/news`、`/login`、`/`
- 対象ファイル:
  - `src/modules/news/ui/news-create-dialog.tsx`、`src/modules/master/ui/master-create-form.tsx`、`src/modules/party/ui/party-form-fields.tsx`（自由記述入力欄）
  - `src/modules/master/ui/master-table.tsx`、`src/modules/party/ui/party-table.tsx`、`src/modules/news/ui/news-item.tsx`（一覧・詳細での表示）
  - `src/modules/master/repository.ts`、`src/modules/news/repository.ts`（検索クエリ）
  - `next.config.ts`（セキュリティヘッダー。本仕様書作成と合わせて`headers()`を追加する）
- 関連DBテーブル: `Master`、`Party`、`News`
- 関連設計書: 各機能の基本設計書（`docs/specs/02_basic-design/`配下）。本タスク固有の方針は `docs/todo/TODO.md`「公開用テンプレートの切り出し前準備」4番を参照。

## 2. 前提条件
- 実行環境: ローカル環境。本番URL・本番DBには接続しない。
- ログインユーザー: ADMINまたはOPERATORを1名（自由記述欄への入力用）。検索系はいずれのロールでもよい。
- 権限: 権限差そのものの確認は対象外（「7. 補足」参照。既存の機能別UT仕様書で確認済み）。
- 事前DB状態: マスタ・契約先・お知らせが最低1件ずつ存在すること。
- 使用するテストデータ:
  - XSS注入用文字列: `<script>alert(1)</script>`
  - SQLインジェクション風文字列: `' OR '1'='1`

## 3. テスト観点
- 正常系: 対象外（各機能の正常系は既存の機能別UT仕様書で確認済みのため、本書では重複させない）
- 異常系: XSS注入、SQLインジェクション風入力
- 境界値: 対象外
- 権限: 対象外（「7. 補足」参照。URL直叩き・ボタン非表示・パスワード再発行のレート制限による確認は既存の機能別UT仕様書で確認済みのため、本書では重複実行しない）
- DB更新: 対象外（本書のテストケースはいずれも参照・表示確認が中心のため）
- 画面表示: XSS注入値がスクリプトとして実行されず、文字列としてエスケープ表示されること
- エビデンス取得: 各ケースの画面をPNGで、レスポンスヘッダー確認ケースはヘッダー内容をテキストで保存する

### その他のスコープ外事項

- **CSRF対策**: Next.js Server Actionsは標準でOrigin検証を行う設計に依拠しており、独自のCSRFトークンは実装していない。Playwrightでの再現テストは技術的に困難なため対象外とする（設計確認のみで担保する）。
- **CSP（Content-Security-Policy）**: Google Fontsの許可設定やUIライブラリのインラインスタイルの洗い出し等、別途の検証工数が必要なため今回は導入を見送る。`docs/todo/TODO.md`の「残っているタスク」へ申し送り、本書でもテスト対象外とする。
- **依存パッケージの脆弱性（`pnpm audit`等）・リポジトリ内の秘密情報混入・インフラ設定（Cloud Run/Supabase）の確認は今回のスコープ外**とする（必要になった時点で別タスクとして扱う）。
- ログイン・認証まわりの基本的な確認（ブルートフォース対策・アカウントロック・ユーザー列挙対策等）は[`UT_10_ログイン画面.md`](../auth/UT_10_ログイン画面.md)で確認済みのため、本書では重複させない。
- お知らせ検索は`sort=startAt`（既定）のときのみ`$queryRaw`（`Prisma.sql`タグ付きテンプレートでパラメータ化済み）を使用し、それ以外の並び替えでは`findMany`の`where`句を使用する。TC-005は既定のままで確認する。
