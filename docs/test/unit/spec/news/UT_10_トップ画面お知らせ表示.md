# 単体テスト仕様書: トップ画面お知らせ表示（NEWS-01）

## 1. テスト対象
- 対象機能: トップ画面お知らせ表示・さらに表示（NEWS-01）
- 対象画面またはAPI: `/`、`loadMoreNewsAction`
- 対象ファイル: `src/app/(main)/page.tsx`、`src/modules/news/ui/news-feed.tsx`、`src/modules/news/ui/news-item.tsx`、`src/modules/news/actions.ts`、`src/modules/news/service.ts`、`src/modules/news/repository.ts`
- 関連DBテーブル: `News`
- 関連設計書: [`10_トップ画面お知らせ表示.md`](../../../../specs/02_basic-design/news/10_トップ画面お知らせ表示.md)、[`01_データベース.md`](../../../../specs/02_basic-design/news/01_データベース.md)

## 2. 前提条件
- 実行環境: ローカル環境。本番URL・本番DBには接続しない。
- ログインユーザー: ADMIN、OPERATOR、VIEWERの各ロール。
- 権限: お知らせの閲覧と「さらに表示」は全ロールに許可される。
- 事前DB状態: 公開中の `INCIDENT`・`MAINTENANCE`・`NEWS` を各1件以上、公開前・公開終了・非公開を各1件以上用意する。さらに表示用に公開中のデータを `env.PAGE_SIZE + 1` 件以上用意する。
- 使用するテストデータ: 本文に改行と `<script>test</script>` を含む公開中のお知らせ、公開開始日時が空欄のお知らせ。

## 3. テスト観点
- 正常系: 公開中のお知らせの表示、カテゴリ優先順、日時・本文・色分け、さらに表示。
- 異常系: 公開中のお知らせが0件の場合の表示。
- 境界値: `env.PAGE_SIZE` 件と `env.PAGE_SIZE + 1` 件での「さらに表示」ボタンの表示切替。
- 権限: 全ロールで閲覧できること。
- DB更新: 読み取り専用であること。
- 画面表示: 本文の改行、HTMLを実行しないこと、取得中のボタン無効化。
- エビデンス取得: 各ケースの画面をPNGで保存する。

## 7. 補足
- さらに表示中に公開状態が変わることで重複または欠落する可能性は設計上許容されているため、再現テストの対象外とする。
- 重複、一意制約、存在しないID、DB制約違反は読み取り専用機能のため対象外とする。
