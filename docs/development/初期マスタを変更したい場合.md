# 初期マスタを変更したい場合

初回セットアップ時に登録するデータ（初期データ）を変更する手順です。初期データの定義は [`prisma/seed.ts`](../../prisma/seed.ts) にあります。

この手順で扱うのは**自分のPCで動かしているローカルDB**だけです。本番環境の初期データを変更したい場合は、接続先を切り替える前に必ず担当者へ確認してください。

## 初期データとは

このプロジェクトには、次のような最初から用意しておくデータがあります。

- 初期管理者（ID: `admin`）
- トップ画面に表示する初期お知らせ
- 契約先分類・契約分類として使うマスタ分類

`pnpm prisma:seed` を実行すると、同じIDやコードのデータがあれば内容を更新し、なければ新しく登録します。既存データを削除する処理は行いません。

## 変更するファイル

プロジェクトのフォルダで [`prisma/seed.ts`](../../prisma/seed.ts) を開きます。`title`、`body`、`name` などを必要に応じて変更してください。

### 初期お知らせのタイトルを変更する

お知らせは `update` と `create` の両方を変更します。

```ts
await prisma.news.upsert({
  where: { id: "seed-welcome" },
  update: {
    title: "サンプル契約管理システムをリリースしました。",
  },
  create: {
    id: "seed-welcome",
    title: "サンプル契約管理システムをリリースしました。",
  },
});
```

- `update` は、すでに登録済みの初期お知らせを変更するときに使います。
- `create` は、データベースが空の状態で初めて登録するときに使います。
- `id` は同じ初期データだと識別するための名前なので、通常は変更しません。

トップ画面では公開日時を別に表示するため、タイトルへ日付を重ねて書く必要はありません。

### 初期マスタ分類の名前を変更する

マスタ分類は `code` を変えず、`update` と `create` の両方へ同じ名前を書きます。

```ts
await prisma.masterCategory.upsert({
  where: { code: "CONTRACT_TYPE" },
  update: { name: "契約の分類" },
  create: { code: "CONTRACT_TYPE", name: "契約の分類" },
});
```

`CONTRACT_COMPANY_TYPE` と `CONTRACT_TYPE` はアプリが分類を探すために使うコードです。これらの値を変えると画面で分類を選べなくなるため、通常は変更しません。

## ローカルDBへ反映する

1. Docker Desktopを起動し、データベースを含むアプリを起動します。起動方法は[プロジェクト実行手順](プロジェクト実行手順.md)を参照してください。
2. プロジェクトのフォルダで、次のコマンドを実行します。

   ```powershell
   $env:DATABASE_URL = 'postgresql://app:password@localhost:5432/app_db'
   pnpm prisma:seed
   ```

3. `Seed 完了` と表示されたら、ブラウザを再読み込みして変更内容を確認します。

この接続先はローカルDocker DBです。コマンドはPowerShellを閉じるまでだけ有効で、ほかのターミナルや本番DBには影響しません。

## 注意すること

- `pnpm db:reset` は、ローカルDBのデータをすべて消してから作り直すコマンドです。初期データを更新するだけなら実行しません。
- 初期管理者のパスワードは、既存の利用者がいる状態でseedを再実行しても変更されません。
- 本番DBに対してseedを実行すると、初期データが本番の内容で更新されます。本番での実行は、接続先・影響範囲・初期管理者パスワードを確認してから行ってください。
